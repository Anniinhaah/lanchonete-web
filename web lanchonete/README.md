# Lanchonete Web

Projeto desenvolvido para a disciplina de Engenharia da Qualidade e Confiabilidade.

## Descrição

Site simples para uma lanchonete contendo:

- Página principal
- Página de promoções
- Estilos CSS
- Arquivo JavaScript para o cardápio

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitFlow

## Como Executar

1. Clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo index.html em um navegador.
